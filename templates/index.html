Documentação do Servidor Go

Bem-vindo à documentação do nosso servidor Go!

Go é uma linguagem de programação compilada, tipada estaticamente e open source. Foi criada no Google em 2009 com objetivo de unir a simlicidade de linguagens como Python com a performance de C / C++

Pontos fortes!

{{.Secao1.Descricao}}

Com uma biblioteca padrão rica com, HTTP, JSON, CRIPTOGRAFIA, TESTE e outros recursos sem depender de frameworks terceiros. Algumas ferramentas integrada como, go build, go test, go fmt, go mod, go vet. Sobre o go build compila os pacotes e suas dependencias, se for uma main func, gera um executavel se for biblioteca verifica se tem erros sem gerar arquivo.exe Esse é um dos pontos fortes: go build lê o go mod, para saber as dependencias compila cada pacotes Usando um cache de build, ele é rapido pois ele vai recompilar apenas os que tiveram mudanças faz o linking, juntando tudo em um binário estático, com o runtime do Go (incluindo o garbage collector) embutido. Ja que um dos objetivos dos criados era otimizar o tempo ao compilar varios codigos.

Funcionamento

Compilada por binariios nativos, o codigo vira um executavel, sem precisar de maquina virtual ou interpretador, Garbage Colector gerencia a memória automaticamnte. Concorrencia embutida, com o Goroutines ele consegue lidar com várias tarefas ao mesmo tempo, alternando entre elas. e execultar tarefaz sumultaneamente em nucleos diferentes garantido uma otima perfoemance.
