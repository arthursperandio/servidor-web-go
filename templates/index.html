Documentação do Servidor Go

Bem-vindo à documentação do nosso servidor Go!

Go é uma linguagem de programação compilada, tipada estaticamente e open source. Foi criada no Google em 2009 com objetivo de unir a simplicidade de linguagens como Python com a performance de C / C++

Seção 1 — Pontos Fortes e Filosofia

{{.Secao1.Descricao}}

A biblioteca padrão é rica, com recursos para HTTP, JSON, CRIPTOGRAFIA, TESTES e outros recursos sem depender de frameworks de terceiros. Algumas ferramentas integradas, como go build, go test, go fmt, go mod, go vet. Sobre o go build compila os pacotes e suas dependencias, se for uma função main, gera um arquivo executável se for uma biblioteca verifica se tem erros sem gerar arquivo.exe Esse é um dos pontos fortes: go build lê o go mod, para saber as dependências compila cada pacote Usando um cache de build, ele é rápido pois ele vai recompilar apenas os que tiveram mudanças faz o linking, juntando tudo em um binário estático, com o runtime do Go (incluindo o garbage collector) embutido. Jáque o objetivo dos criadores era otimizar o tempo ao compilar vários códigos.

Funcionamento

O código é compilado para binários nativos e se transforma em um executável, sem precisar de uma máquina virtual ou de um interpretador. O Garbage Collector gerencia a memória automaticamente. A concorrência é integrada à linguagem: com goroutines, o Go consegue lidar com várias tarefas ao mesmo tempo, alternando entre elas e executando tarefas simultaneamente em diferentes núcleos, garantindo uma ótima performance.
