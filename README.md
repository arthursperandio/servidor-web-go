## Tecnologia
Go (Golang), utilizando o pacote net/http.

## Objetivo
Desenvolver um servidor web funcional que disponibilize
uma documentação sobre Go em formato JSON.

## Pré-requisitos
- Go instalado
- Visual Studio Code
- Postman (opcional)

Content-Type: application/json

## Funcionalidades
- Servidor HTTP na porta 8080
- Rota principal GET /
- Documentação em JSON
- Tratamento de rotas que não existem
- Validação do método HTTP

## URL
http://localhost:8083/
http://localhost:8083/api/docs
